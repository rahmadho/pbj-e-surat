# eSurat

eSurat adalah aplikasi berbasis web untuk manajemen surat. Proyek ini dibuat awalnya internal salah satu instansi pemerintahan daerah. Proyek ini dikembangkan menggunakan PHP native. Projek ini merupakan perbaikan dari Source Code orang lain, disini saya hanya melakukan perbaikan kode sehingga bisa berjalan di PHP versi 8.3

## Fitur
- Otentikasi pengguna
- Manajemen surat 
- Upload dan unduh dokumen
- Disposisi surat

## Instalasi

1. Clone repositori di direktori web server:
    ```bash
    git clone https://github.com/rahmadho/pbj-e-surat.git
    ```
2. Buat database dan impor file .sql di folder ./database:
3. Copy file `.env.example` ke `.env` dan sesuaikan konfigurasi sesuai database yang sudah dibuat.
4. Jalankan aplikasi di browser
